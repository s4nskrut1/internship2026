## ✦ What this explores

The project focuses on the less glamorous — but very real — side of frontend work: making forms clear, responsive and pleasant to use.

### Includes

- Responsive contact form
- Client-side validation
- Inline validation feedback
- Submission flow
- Saved-submission view
- Responsive styling
